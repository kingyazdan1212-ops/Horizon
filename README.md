# Horizon

**Multi-model AI chat for clear thinking, decisions, coding and creativity.**

Open-source, beautiful, and ready for the world.

## Features

- Multi-model support (OpenAI, Claude, Gemini, Llama, DeepSeek… via OpenRouter or direct)
- Modes: General • Decision Advisor • Coding • Creative
- Streaming responses
- Conversation history (local)
- Progressive Web App
- Clean dark interface

## Quick start

1. Open `index.html` or deploy to GitHub Pages / Vercel / Netlify
2. Click **Settings** and add your API key (recommended: [OpenRouter](https://openrouter.ai))
3. Start chatting

## Deploy

Just push the files to a GitHub repository and enable GitHub Pages.
